% The Physics Teacher (TPT) anonymous submission template
%
% Journal features:
% - TPT focuses on practical and classroom-facing physics teaching.
% - Manuscripts are usually concise, readable, and useful to physics teachers.
% - This template is anonymous by default; keep author names and affiliations out
%   of the review file unless the journal asks otherwise.
% - TPT generally does not use a separate abstract. Use the opening paragraph to
%   make the article's teaching purpose and value clear.
%
% Before submission:
% - Check the current AAPT/TPT author instructions and AIP submission system.
% - Initial submission normally uses one self-contained PDF with text, figures,
%   tables, and references; accepted/revised files may require editable source files.
% - TPT papers are generally short. Keep the manuscript classroom-ready and concise.
% - Use line numbers for the original submission and remove them when final files are requested.
%
% Editing tips:
% - Start by editing the title and section files in sub/.
% - Put the practical teaching idea early. Teachers should understand what they can use.
% - Keep references selective and useful; avoid letting literature review dominate the article.
% - Tables should be understandable by themselves and placed near the end if following TPT style.
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
