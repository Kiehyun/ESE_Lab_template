## 상세 기록 — Zotero 설치

### 설치 방법 (재현 절차)
1. **패키지 확인**: `winget search Zotero` → 정식 ID는 `DigitalScholar.Zotero` (버전 9.0.5).
   - 주의: `Zotero.Zotero`로는 검색되지 않음(과거 ID). 반드시 `DigitalScholar.Zotero` 사용.
2. **설치 명령**:
   ```powershell
   winget install --id DigitalScholar.Zotero --source winget `
     --accept-package-agreements --accept-source-agreements --silent
   ```
   - 다운로드 원본: `https://download.zotero.org/client/release/9.0.5/Zotero-9.0.5_x64_setup.exe`
   - 설치 관리자 해시 검증 통과 → "설치 성공".

### 설치 결과 (검증)
- 실행 파일: `C:\Program Files\Zotero\zotero.exe`
- 버전: FileVersion / ProductVersion = **9.0.5**
- winget 등록: `winget list --id DigitalScholar.Zotero` → 9.0.5 (winget 원본)
- 실행 테스트: `Start-Process` 후 `zotero` 프로세스 7개 정상 기동(멀티프로세스 구조 = 정상). GUI 창 뜸.

### 사용 방법 (첫 실행 이후 — 사용자 수동 단계)
Zotero 프로그램 설치는 끝났으나, **문헌 라이브러리로 쓰려면 아래 초기 설정은 사용자가 직접** 해야 합니다:
1. **첫 실행 안내**: Zotero 창에서 데이터 저장 폴더 지정(기본 `%USERPROFILE%\Zotero`).
2. **계정 연동(선택)**: `Edit > Preferences > Sync`에서 무료 zotero.org 계정 로그인 → 여러 기기 동기화(무료 300MB, 초과 시 유료/WebDAV).
3. **브라우저 커넥터 설치**: <https://www.zotero.org/download/connectors> 에서 Zotero Connector(크롬/엣지/파이어폭스) 설치 → 논문 페이지에서 원클릭으로 서지+PDF 저장.
4. **워드 플러그인**: Zotero 실행 상태로 `Preferences > Cite > Word Processors`에서 설치 → Word/LibreOffice 인용·참고문헌 자동 생성.
5. **자료 넣기**: DOI/ISBN로 "마법봉"(Add by Identifier) 입력, 또는 커넥터로 웹에서 수집, 또는 PDF 드래그&드롭(메타데이터 자동 추출).
